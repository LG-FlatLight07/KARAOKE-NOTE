# 十八番ノート

カラオケのレパートリー（十八番）を、歌い出し・キー・平均点つきで一覧にする個人用Webアプリ。`index.html` 1枚で動きます。

## 機能
- 曲名を入れて登録。歌詞は [LRCLIB](https://lrclib.net) から自動取得。同名曲が複数あればアーティスト名を聞き、見つからなければ「歌詞なし」か「手入力」
- キーは −/+ のワンボタンで ±7 まで
- 点数の記録、曲ごとの平均点、履歴（推移グラフ付き）
- おまかせ選曲（ランダム）
- 曲名・平均点・追加順で並べ替え、曲名/アーティストで絞り込み
- ライト／ダーク両対応

## データの保存
- データはブラウザの localStorage（その端末・そのブラウザの中）に保存されます。サーバーには送りません。
- 別の端末へ移すときは、ページ下の「バックアップを保存」で JSON を書き出し、移動先で「バックアップから復元」。
